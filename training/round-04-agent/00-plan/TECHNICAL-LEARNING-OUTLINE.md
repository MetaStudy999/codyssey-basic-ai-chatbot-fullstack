## 5. 한글·영어·공식 약어와 설명·재현 확인

**첫 표기:** 한글명(English Full Name, 공식 약어). 원래 약어가 없는 용어에는 새 약어를 만들지 않습니다.

| 한글명 | 영어 원명 | 공식·통용 약어 | 입문 설명 |
|---|---|---|---|
| **프론트엔드** | Frontend | 없음 | 이용자의 화면·입력 담당 |
| **백엔드** | Backend | 없음 | 서버의 비즈니스 로직·데이터 처리 |
| **데이터베이스** | Database | DB | 데이터 저장·조회 관리 |
| **거대 언어 모델** | Large Language Model | LLM | AI 언어 모델 |

**자기 설명:** 프론트엔드(Frontend)는 이용자가 보는 화면을 처리하고, 백엔드(Backend)는 서버의 데이터·외부 API·권한 처리를 담당합니다.

**종이 재현 예상 단계**
1. 브라우저에서 대화 입력을 보내는 상황 가정.
2. 서버가 요청을 검증하고 AI API 연결 여부 결정.
3. 정상 응답 또는 오류 안내가 화면으로 돌아옴.

**흔한 오해:** 브라우저로 배포한 JavaScript에 비밀 API 키를 직접 포함하는 것은 안전하지 않습니다.

**학습 확인:** 핵심 용어를 직접 설명할 수 있나요? 입·처리·출력 순서를 자료 없이 다시 그릴 수 있나요? 실제 테스트 여부를 구별할 수 있나요?
