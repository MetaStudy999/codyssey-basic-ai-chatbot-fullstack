# B7-2 학습자 중심 AI 교육·학습 계획 V1.0

> 사용자 승인 **2026-10-26**. 기획·문서·폴더 반영만 해당. 미션 개발 승인 PENDING, 콘텐츠 제작·실습 실행·학습자 평가 NOT_STARTED/NOT_VERIFIED.

**해당 미션 기술:** AI 챗봇 풀스택·API·데이터 흐름·서비스 검증. 해당 공식 PDF 및 평가 요구 우선.

## 교육 목표
한글명(English Full Name, 약어)·정의·개념 연결→실행 예상→코드 추적→독립 구현→오류 해결→자기 설명→새 문제 응용.

## 16가지 학습 방법
- M01 Flashcard/용어
- M02 개념 관계도
- M03 4컷 만화
- M04 Why 질문
- M05 기술 비교
- M06 실행 결과 예측
- M07 코드 추적
- M08 Parsons 순서 맞추기
- M09 코드 빈칸
- M10 코드 수정
- M11 Debugging
- M12 백지 구현
- M13 자기 설명
- M14 Transfer/전이
- M15 간격 복습·혼합
- M16 AI 튜터·오답

**PRIMM** Predict→Run→Investigate→Modify→Make; **H1~H4** 질문→개념→절차→해설 힌트, 실제 도움 수준 기록; **L1~L5** 코드 보며→도식만→무자료→백지 재현→새 문제 적용. 복습 운영안 직후·1·3·7·14·30일, 실제 오답 따라 조정. 사전·사후 동등 난도 평가.
